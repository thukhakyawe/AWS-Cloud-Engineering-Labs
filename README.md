# AWS Cloud Engineering Labs


> Production-ready AWS implementations, infrastructure as code, and architectural patterns for cloud engineers.

## 🚀 Overview

A comprehensive collection of AWS labs and projects demonstrating real-world cloud architecture, DevOps practices, and scalable solutions. From fundamental services to complex multi-service deployments.

## 📁 Lab Categories

### 🧪 Hands-On Experiments
- Service-specific implementations and proof-of-concepts
- **Examples**: S3 static hosting, Lambda functions, DynamoDB tables

### 📚 Learning Paths  
- Structured progressions and certification preparation
- **Examples**: Solutions Architect labs, Security specialization, Networking deep dives

### 🏗 Production Architectures
- Enterprise-grade patterns and operational excellence
- **Examples**: Three-tier web apps, Data pipelines, Microservices

## 🛠 Tech Stack

**Infrastructure**: Terraform, AWS CDK, CloudFormation  
**Compute**: EC2, Lambda, ECS, EKS  
**Storage**: S3, RDS, DynamoDB, EFS  
**Networking**: VPC, CloudFront, API Gateway  
**DevOps**: CodePipeline, CloudWatch, IAM

## 🏁 Getting Started

Each lab are separated and includes it owns:
- 📋 Prerequisites and setup instructions
- 🏗 Architecture diagrams
- ⚡ Deployment scripts
- 🔧 Cleanup procedures

Browse directories by using name to begin.
